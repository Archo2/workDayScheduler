# Work Day Scheduler

A simple daily planner for standard business hours (9 AM to 5 PM) that saves your tasks in the browser.

**Live demo:** https://archo2.github.io/workDayScheduler/

## Features

- Shows today's date at the top of the page
- One time block per business hour
- Color-coded blocks: gray for past hours, red for the current hour, green for future hours
- Click **Save** on a block to store its text in `localStorage`, so it's still there after a page refresh

## Built With

HTML · CSS · JavaScript · jQuery · Bootstrap · Moment.js

## How to Use

1. Open the [live demo](https://archo2.github.io/workDayScheduler/) or open `index.html` in your browser.
2. Type an event into any hour.
3. Click the save icon on that row.
